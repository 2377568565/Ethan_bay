# 显卡驱动一键更新（Intel 核显 + NVIDIA MX150）

双击 `显卡驱动一键更新.bat`，弹窗点“是”。全程需要联网、插电源，下载约 1GB。

1. 先创建系统还原点“更新显卡驱动之前”
2. 从 Intel 官网下载页实时读取 7th-10th 代核显驱动的最新地址，下载、校验 Intel 数字签名、静默安装
3. 用 NVIDIA 官网驱动查询接口（MX150 笔记本，Win11/Win10）读取最新驱动，下载、校验 NVIDIA 数字签名、清洁安装
4. 已经是最新版的会跳过；静默安装失败会改为打开安装界面
5. 装完 60 秒倒计时自动重启，按 N 取消

安装时屏幕闪烁、黑几秒属于正常，不要强制关机。
