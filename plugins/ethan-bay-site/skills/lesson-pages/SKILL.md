# 逐课研读页

## 用户最初定下的要求（2026-09-27）
每一课、每一天都要有：**核心概述、以经解经、精准回答思考问答、需要提升的认知、上帝的心意、我们的行动**；
可以超出学课本身，用圣经和怀著扩展深入。每课开头 1–2 段精炼总结（含圣经和怀著），让没读过学课的人也能马上抓住核心。
用途：发到微信群里各人预备，也在安息日学班上投屏。

后来陆续定下的版式（都已实现，改动时不要破坏）：
- **原文在前、解读在后**；导言单独一章，放在第 1 课前面。
- 顶部两排导航按钮（“原文”一排在上、“解读”一排在下），往下读时固定在顶部；**切换时两排按钮不能跳动**（只让正文做翻页动画）。
- 原文的思考题旁有“看参考解答 →”，解读里的学课原题有“↩ 回到原文问题”，两边互相跳。
- 每天标题下有“阅读本日学课原文 →”/“查看本日解读 →”按钮。
- 经文出处可以点：弹出和合本、NKJV（或 KJV）、希伯来文/希腊文逐字，以及“直译连读”的英文和**中文直译**两行。
- 按设备日期自动推荐本周学课（金框和星星）；学课一周算到那个安息日下午的班为止（START = 2026-09-26 星期六）。
- 从首页进“今日学课”先到原文；读完原文再打卡；需要时再看解读。导言（安息日下午）也有打卡。

## 文件
- `tools/q4/data/lNN.py`：一课的全部解读（第 1 课例外，是手写片段 `l01_frag.html`）。
- `tools/q4/pdf_blocks.json`：从季刊 PDF 提取的原文块；`gen_yw.py` 把它排成“学课原文”；个别页面提取有误时在 `lNN.py` 的 `OVERRIDES` 里手写。
- `tools/q4/zhlit/zhlit.json`：原文逐字的中文直译（经文弹窗用）。
- `tools/q4/render.py`：组装；`welcome.py` 欢迎页；`intro.py` 导言；`app.js`/`base.css`/`extra.css` 交互与样式。

## `lNN.py` 的格式
```python
NO = 5
L = dict(
  title='启示与默示', gist='一句话概括', mem_ref='启示录1:1、2', mem='存心节原文', readings='本周经文',
  essence=['本课精要第1段', '第2段（含圣经、怀著）'],
  arc=[('启示', '上帝揭开真理', '来1:1', False), ...],   # 本课一条线；最后一项 True = 高亮
  arc_cap='一句话说明这条线',
  days=[dict(key='sab'|'sun'|'mon'|'tue'|'wed'|'thu'|'fri', title='', texts='本日经文',
             core=['核心概述段落', ...],
             pairs=[('经文A ↔ 经文B', '两处经文怎样互相解释'), ...],       # 以经解经，↔ 分隔
             egw=[('怀著引文（中文）', '怀爱伦，《书名》，原文第N页'), ...],
             qa=[dict(t='q', q='学课原题', a=[...], my=True),            # t='q' 学课原题；t='e' 延伸思考
                 dict(t='e', q='延伸问题', a=[...])],
             shift=[('原来的想法', '提升后的认知'), ...],
             heart='上帝的心意（一段）',
             acts=['行动 1', ...]), ...],
  kxx=dict(know=[...], believe=[...], do=[...]),     # 总结：知 · 信 · 行
  discuss=['安息日班讨论建议', ...], recite='本周背诵',
)
OVERRIDES = {'tue': ('标题', [('p', '段落'), ('q', '思考题'), ('html', '<table>…</table>')])}   # 可选
```
- `a`（答案）和 `core` 里的每一项：字符串 = 段落；`('ul'|'ol', [...])` 列表；`('table', 表头, 行)` 表格；`('egw', 引文, 出处)` 怀著方框。
- 文字里 `**粗体**`；括号里的经文出处（如“（约14:30）”）会自动变成可以点的经文。
- **每天 `t='q'` 的题数必须等于原文那天的思考题数**，否则生成时报错停止（这是为了原文和解答一一对应）。

## 写作规范
- 经文用和合本（上帝版）原文逐字；怀著按英文原著页码引用，中文是编者译，必须核对过（见 `verify-sources`）。
- 语言精炼、温暖、有逻辑；先讲清经文本身，再讲应用。不确定的地方写“编者的理解”。
- 避开 1949 年以后的政治话题和敏感词（读者在中国大陆）。
- 改完：`python3 tools/q4/render.py all`，然后按 `publish` 检查发布；段落有增减的，按 `tts-audio` 补录。

## 做下一季时（参考）
2026 Q4 这一套可以照搬：
1. 季刊 PDF 放在本机（不提交），`Q4_PDF=季刊.pdf python3 tools/q4/extract.py --cache` 重新提取原文块。提取规则见 `extract.py`、`gen_yw.py`：楷体粗体 = 思考题；思源宋体粗体、14 号以上 = 每天标题；小于 9.5 号 = 经文出处。
2. 改 `render.py` 的 `Q_START`（第 1 课安息日下午的日期）和各处“2026年第4季”“预言的恩赐”字样；欢迎页经文池在 `welcome.py`。
3. 先做第 1 课给用户看，满意了再做其余各课（用户 2026-09-27 就是这样要求的）。
4. 问清楚：新网站放在新的网址/文件夹，还是替换现在这一季（现在这一季有读者的打卡、提问、账号数据）。
