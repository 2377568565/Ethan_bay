# 一键工具（单文件 bat，双击即用）

每个 bat 都是独立的一个文件，双击后会自动请求管理员权限（弹窗点“是”）。

## 一键回收内存.bat（给新电脑用）
回收各程序闲置的内存 + 清空备用缓存，显示释放了多少，5 秒后自动关闭。

## 老电脑一键加速.bat（给老电脑用）
按顺序自动执行：
1. 开启专注模式：前台程序优先、关动画和透明、右键菜单秒开、禁止后台应用（已开启过会自动跳过）
2. 清理磁盘垃圾：临时文件、错误报告、旧更新包、浏览器缓存（浏览器开着会跳过）；不碰回收站和个人文件
3. 回收闲置内存
4. 启动实时专注：在任务栏上开一个最小化的小窗口，持续给当前程序提速、给后台程序降速；点开它按 Q 退出并自动恢复
5. 列出占 CPU 高的程序，**你输入编号并确认后**才关闭，直接回车跳过

## 恢复默认设置.bat（给老电脑用）
撤销第 1 步“专注模式”的全部改动（原值在第一次开启时备份到 `%LOCALAPPDATA%\PcFocusMode\backup.json`）。
