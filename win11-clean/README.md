# 一键清理（CPU + 磁盘 + 运行内存）

把 `clean.bat` 和 `clean.ps1` 放在同一个文件夹，双击 `clean.bat`，弹窗点“是”。

| 步骤 | 做什么 |
| --- | --- |
| 1. CPU | 列出你自己打开的、占用偏高的程序，输入编号可以关掉（系统程序不会列出来，关之前会再确认） |
| 2. 磁盘 | 清理临时文件、系统错误报告、10 天前的旧更新安装包、浏览器缓存（浏览器开着会跳过）、更新传递优化缓存；回收站会先问你 |
| 3. 内存 | 回收各程序闲置的内存、清空备用缓存 |

最后会显示清理前后的已用内存和 C 盘剩余空间。

不会动：文档、照片、下载、桌面等个人文件；系统进程；注册表。
