# 专注加速

让 CPU 优先照顾你正在用的程序，减少后台干扰，打开软件 / 右键 / 网页更跟手。

把 `focus.bat` 和 `focus.ps1` 放在同一个文件夹，双击 `focus.bat`，弹窗点“是”。

| 数字 | 功能 | 说明 |
| --- | --- | --- |
| 1 | 开启专注模式 | 前台程序分到更多 CPU 时间；菜单弹出 400ms -> 100ms；关闭窗口动画、任务栏动画、透明效果；右键菜单换成经典样式（秒开）；禁止应用商店类应用后台运行；打开“启动应用”让你关掉没用的开机自启 |
| 2 | 实时专注 | 窗口开着期间，每 2 秒把你当前在用的程序调到“高于正常”，把后台占 CPU 超过 3% 的程序调到“低于正常”。按 Q 退出，自动全部恢复 |
| 3 | 管理开机自启 | 打开任务管理器的“启动应用”页面 |
| 4 | 恢复默认 | 按备份把第 1 项的改动全部撤销 |

安全性：
- 第 1 项改动前会把原值备份到 `%LOCALAPPDATA%\PcFocusMode\backup.json`，第 4 项按它恢复。
- 不关闭任何系统服务；系统进程（C:\Windows 下的程序、杀毒等）不会被调整优先级。
- 实时专注只调整优先级，不会关闭任何程序。
