# 电脑卡顿急救 / 降温 / 体检

## 用法

1. 把 `speedup.bat` 和 `speedup.ps1` 放在**同一个文件夹**里（压缩包要先解压）。
2. 电脑卡的时候，双击 `speedup.bat`，弹窗点 **是**。
3. 按菜单输入数字：

| 数字 | 功能 | 说明 |
| --- | --- | --- |
| 1 | 卡顿急救 | 显示 CPU / 内存 / 硬盘占用和最占资源的程序，可以输入编号关掉它；顺便清理临时文件 |
| 2 | 降温模式 | 把 CPU 最大状态设为 99%（关闭睿频），满载温度通常降 10~20 度，日常使用基本无感 |
| 3 | 恢复默认 | CPU 最大状态改回 100% |
| 4 | 电脑体检 | 检查内存条是否都识别到、硬盘健康、C 盘空间、缺失的驱动、后台更新、开机自启项 |
| 5 | 重启任务栏 | 任务栏 / 桌面卡死时用 |

## 安全性

- 不改注册表，不永久关闭任何系统服务。
- 系统进程（C:\Windows 下的程序、杀毒、系统更新等）不会出现在可结束的选项里。
- 结束程序前会再问一次，你确认后才执行。
- 降温模式只改了电源计划里的一个数值，选 3 就能恢复。

## 温度高的根本解决办法

2018 年的笔记本，风扇积灰、导热硅脂干了是最常见的原因。找电脑店清灰 + 换硅脂，通常能降 15~25 度。
