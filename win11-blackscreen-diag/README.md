# 黑屏诊断

双击 `黑屏诊断.bat`，弹窗点“是”。它会：

1. 读取最近 30 天的系统日志：每次强制关机发生在什么状态（睡眠/唤醒中、开机或使用中、蓝屏）、睡眠和唤醒次数、显卡驱动崩溃、硬件错误（WHEA）、蓝屏转储、硬盘错误
2. 检查 BIOS 日期、显卡驱动版本、内存条、快速启动、合盖动作、放着不动多久关屏幕/睡眠、屏幕保护
3. 给出诊断结论和“黑屏时自测”的方法
4. 把报告保存到桌面 `黑屏诊断报告.txt`
5. 最后几个可选修复（关闭快速启动、合盖改休眠、插电不自动睡眠、内存检测）每一项都会先问你，不同意就不改

# 黑屏深度诊断

双击 `黑屏深度诊断.bat`，弹窗点“是”。在第一份报告的基础上进一步检查：

1. 主板 / BIOS 型号
2. 所有蓝屏 / 意外关机的错误码和参数
3. 每次出事前 30 分钟内的错误和警告
4. 开机方式统计（冷启动 / 快速启动 / 休眠恢复）
5. 显卡详情（驱动来源、问题代码、硬件 ID）
6. 正在运行的第三方内核驱动（标出安全/优化类软件的驱动）
7. 内存条详情
8. 锁屏后关屏时间
9. 用微软 WinDbg 分析蓝屏转储，找出肇事驱动（没装会先问你要不要用 winget 安装）

报告保存到桌面 `黑屏深度诊断报告.txt`，蓝屏完整分析保存到 `蓝屏分析详情.txt`。
